# Aman Finance

**Personal financial analytics dashboard built with Python and Streamlit.**

Aman Finance turns everyday transaction data into a simple reporting workspace for understanding income, expenses, savings and spending patterns.

## Why I built it

I wanted to combine my interest in **finance and programming** into a practical project rather than building a purely academic example.

The application focuses on a small but realistic workflow: record transactions, organize them, review trends and export the underlying data.

## Core features

- Financial overview dashboard
- Income, expense and net-savings metrics
- Savings-rate calculation
- Monthly reporting filter
- Income vs expense cash-flow chart
- Expense-by-category analysis
- Recent transaction table
- Transaction entry form
- CSV import/export
- Basic validation and empty states

## Tech stack

- Python
- Streamlit
- Pandas
- CSV

## Project structure

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

The app opens in your browser.
